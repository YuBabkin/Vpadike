# Публикация «Доски объявлений» на хостинге Majordomo

Приложение — Flask + SQLAlchemy (SQLite). Majordomo поддерживает Flask через **uWSGI** в рамках тарифа «Хостинг приложений». Хостинг клонирует Git-репозиторий, создаёт виртуальное окружение, ставит зависимости из `requirements.txt` и запускает приложение через WSGI.

## Что уже сделано в проекте

- `app.py` — WSGI-приложение. Объект `app` в файле `app.py`, точка входа: **`app:app`**.
- `requirements.txt` — зависимости (`flask`, `flask-sqlalchemy`).
- База `instance/notes.db` создаётся автоматически при первом запуске; путь абсолютный и стабильный.
- `.gitignore` — исключает `*.db`, `instance/`, `*~`, `__pycache__`.

Проверка локально:

```bash
python3 -c "from app import app; print('OK', app)"
```

## Шаг 1. Загрузить код в Git-репозиторий

Репозиторий уже создан на GitHub: **https://github.com/YuBabkin/Vpadike.git** (ветка `main`).

1. Убедитесь, что remote `origin` указывает на этот репозиторий:

```bash
git remote -v
# origin  https://github.com/YuBabkin/Vpadike.git (fetch)
# origin  https://github.com/YuBabkin/Vpadike.git (push)
```

2. Если ссылка другая — замените:

```bash
git remote set-url origin https://github.com/YuBabkin/Vpadike.git
```

3. Закоммитьте изменения и отправьте в `main`:

```bash
git add .
git commit -m "Подготовка к деплою на Majordomo: requirements, пути"
git branch -M main
git push -u origin main
```

В репозитории должны быть `app.py`, `templates/index.html`, `requirements.txt`, `.gitignore` и этот файл. `notes.db` и `instance/` попадать не должны.

## Шаг 2. Купить хостинг и домен

1. На majordomo.ru закажите тариф **«Хостинг приложений»** (от ~179 ₽/мес).
2. На странице **«Сводка»** нажмите **«Добавить сервис»** → **uWSGI Python** (200 ₽/мес). MySQL — по желанию.
3. Зарегистрируйте/привяжите домен в разделе **«Домены»**.

## Шаг 3. Добавить сайт и указать точку входа

1. **«Сайты»** → **«Добавить сайт»**, укажите домен.
2. Интерпретатор сайта = **«Выделенный Python»**.
3. **«Точка входа в веб-приложение»** = `app:app`.
4. Сохраните.

## Шаг 4. Подключить Git-репозиторий

1. Вкладка **«Приложение»** в настройках сайта.
2. Ссылка на репозиторий: `https://github.com/YuBabkin/Vpadike.git`.
3. Ветка: `main`.
4. Для приватного репозитория — логин и Personal Access Token (GitHub: Profile → Settings → Developer settings → Tokens).
5. **«Загрузить приложение»** — клонирует код в корень сайта.
6. **«Установить зависимости»** — создаёт venv и ставит пакеты из `requirements.txt` (1–3 минуты).
7. **«Установить приложение»** — запуск.

Репозиторий копируется **без субмодулей**.

## Шаг 5. Проверка

- Откройте `http://ваш-домен` — должна появиться зелёная «стена подъезда».
- Добавьте объявление — запись сверху с автором и временем.
- `http://ваш-домен/notes` должен вернуть JSON.

Если не работает:

- Проверьте точку входа — ровно `app:app` (без `.py`).
- Убедитесь, что `requirements.txt` в корне репозитория.
- Смотрите логи uWSGI в панели (раздел сайта → логи).
- Пишите на support@majordomo.ru.

## Шаг 6. Обновления

- Меняйте код локально, коммитьте, пушите в `main`.
- В панели — **«Обновить приложение»** (git pull).
- Если менялись зависимости — **«Установить зависимости»** снова.

## Шаг 7. Данные (SQLite)

- `instance/notes.db` живёт на сервере, в git не попадает — это правильно.
- «Обновить приложение» данные не теряет (папка `instance` из git не перезаписывается).
- Периодически скачивайте резервную копию: «Расширенное резервное копирование» или просто `instance/notes.db` по FTP/SFTP.
- Для полноценной СУБД — перейти на MySQL (отдельная задача).

## Шаг 8. SSL (HTTPS)

1. Сайт → раздел **«SSL»** → выпустить бесплатный сертификат (Let's Encrypt).
2. Открывайте `https://ваш-домен`.
